STANDARD OPERATING PROCEDURE: Active Directory User Password Reset
Document ID: SOP-IT-001
Owner: Alice Walker, IT Support Lead
Effective Date: 2026-10-15
Department: IT Service Desk

1. Purpose
This procedure defines the authorized process for resetting domain user passwords upon validated identity verification.

2. Scope
Applies to all Level 1 Service Desk technicians handling employee credential resets.

3. Preconditions
- Requester identity has been verified via callback or employee badge ID.
- Operator possesses active Service Desk administrative privileges.

4. Procedure
1. Open PowerShell terminal with elevated administrator privileges.
2. Search and locate the user account in Active Directory using Get-ADUser cmdlet.
3. Reset the target account password using Set-ADAccountPassword with temporary complex credentials.
4. Flag the user account to require password change at next logon using Set-ADUser -ChangePasswordAtLogon $true.
5. Notify the employee securely via SMS or corporate one-time link.

5. Escalation Criteria
If the user account is locked due to security hold, escalate immediately to Security Operations.
