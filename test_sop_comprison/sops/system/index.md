# System Playbooks Catalog

- [Corrupted System File Repair using DISM and SFC](./SOP-SYS-002-001.md) - This playbook repairs corrupted operating system files, resolves application hangs, addresses random Blue Screen of Death (BSOD) errors, and restores core Windows stability using DISM and SFC tools.
- [Check and Terminate a Hung Application – Windows](./SOP-hung-application-001.md) - This playbook verifies if a specified application is running on a Windows system and, if confirmed to be running and unresponsive, forcibly terminates its process.
