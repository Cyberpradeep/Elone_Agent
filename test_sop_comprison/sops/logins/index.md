# Logins Playbooks Catalog

- [How to Unlock a User's Account](./SOP-AUTH-001.md) - This playbook automates the process of unlocking a user's account on the L1 Support Platform after repeated failed login attempts, ensuring quick resolution and preventing duplicate tickets. It includes steps to search for the user, confirm their lock status, and perform the unlock action, with a check for security review locks that require escalation.
- [How to Reset a User's Password (Admin-Assisted)](./SOP-AUTH-003.md) - Admin-assisted password reset for users unable to use self-service, allowing direct temporary password setting or reset link generation based on admin choice.
- [How to Reset a User's MFA Device](./SOP-AUTH-004.md) - This playbook automates the process of resetting a user's Multi-Factor Authentication (MFA) device when they lose or replace their phone, ensuring they can regain access to their account.
- [Disable MFA for a User](./SOP-AUTH-006-001.md) - This playbook disables Multi-Factor Authentication (MFA) for a user after confirming their current password, as requested by the user or admin.
- [Handle Suspicious Login Report](./SOP-AUTH-007-001.md) - This playbook automates the handling of a suspicious login report by reviewing recent login activity for a user's account and locking the account as a precautionary measure. The playbook ensures compliance with security protocols by escalating the issue to the security team after locking the account.
- [Find a User's Account Using Partial Details](./SOP-AUTH-009-001.md) - This playbook automates the process of searching for a user's account in the L1 Support Platform using partial details (e.g., partial email, name, or employee ID). It ensures the correct account is identified before proceeding with further actions.
- [Account Unlock Procedure](./SOP-account-unlock-procedure-001.md) - This playbook automates the procedure for unlocking a user account in the support platform. It searches for the user by email, checks if the account is locked, unlocks it if necessary, verifies the unlock, and sends a confirmation email to the user.
- [Auth0 User Account Maintenance Procedure](./SOP-auth0-user-account-maintenance-procedure-001.md) - This playbook automates the process of searching for an Auth0 user account by email, checking if the account is locked, unlocking it if necessary, and verifying the updated status.
