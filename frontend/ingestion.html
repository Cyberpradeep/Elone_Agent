Ingestion Tips

Use clear, numbered steps
Each step is mapped 1:1 to a tool call — ambiguous steps fail deterministic validation.
Reference exact tool actions
Steps naming concrete actions (reset password, lock account, send email) map reliably to the tool catalog.
Keep SOPs updated
Re-ingest after edits so embeddings and execution steps reflect the latest procedure.
