# Corrupted System File Repair using DISM and SFC Playbook

## Overview
This playbook repairs corrupted operating system files, resolves application hangs, addresses random Blue Screen of Death (BSOD) errors, and restores core Windows stability using DISM and SFC tools.

## Execution Steps
- **Step 1**: Check the local Windows Component Store image repository integrity using DISM ScanHealth. (`DISM /Online /Cleanup-Image /ScanHealth`)
- **Step 2**: If errors or component corruption are reported by ScanHealth, execute DISM RestoreHealth to recover the servicing image. (`DISM /Online /Cleanup-Image /RestoreHealth`)
- **Step 3**: Scan the active operating system files for integrity violations using System File Checker (SFC). (`sfc /scannow`)
- **Step 4**: Safely restart the workstation to finalize any repairs made by DISM or SFC. (`shutdown /r /t 0`)
