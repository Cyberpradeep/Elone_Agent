# Corrupted System File Repair Playbook

## Overview
This playbook automates the repair of corrupted operating system files on Windows 10 and 11 using DISM and SFC tools. It aims to resolve application hangs, patch random Blue Screen of Death (BSOD) errors, and restore core Windows stability by checking and repairing the Windows Component Store and active system files, followed by a system reboot.

## Execution Steps
- **Step 1**: Check the local Windows Component Store integrity using DISM ScanHealth to identify any corruption. (`DISM /Online /Cleanup-Image /ScanHealth`)
- **Step 2**: Execute DISM RestoreHealth to repair component store corruption if detected by the previous scan. (`DISM /Online /Cleanup-Image /RestoreHealth`)
- **Step 3**: Execute System File Checker (SFC) scan to verify and repair active operating system files. (`sfc /scannow`)
- **Step 4**: Perform a system reboot to finalize any repairs made to the operating system files. (`shutdown /r /t 0`)
