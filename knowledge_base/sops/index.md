# Active Playbooks Catalog

- [Unlock a User's Account](./logins/SOP-AUTH-001-001.md) - Category: `logins` - This playbook automates the process of unlocking a user's account in the L1 Support Platform. It searches for the user by email, confirms their lock status, and unlocks the account if it is locked due to failed login attempts.
- [Account Unlock Procedure](./logins/SOP-account-unlock-procedure-001.md) - Category: `logins` - This playbook automates the procedure for unlocking a user account in the support platform. It searches for the user by email, checks if the account is locked, unlocks it if necessary, verifies the unlock, and sends a confirmation email to the user.
- [AirRetailer VPN and Remote Desktop Setup Playbook](./network/SOP-airretailer-vpn-rdp-setup-001.md) - Category: `network` - This playbook automates the setup of AirRetailer VPN using Cisco AnyConnect and establishes a remote desktop connection to an office PC. It covers deriving the VPN username, logging into the VPN portal, downloading and installing the VPN client, configuring VPN settings, connecting to VPN, collecting the local IP address, and setting up a remote desktop session.
- [Software Application Unblock Request (IFEO Debugger Entry Removal)](./software/SOP-L1-APP-001.md) - Category: `software` - This playbook automates the identification and removal of an Image File Execution Options (IFEO) debugger entry blocking a software application on a Windows endpoint. It includes connectivity checks, registry queries, block removal, policy refresh, and verification.
