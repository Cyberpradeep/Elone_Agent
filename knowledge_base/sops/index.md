# Active Playbooks Catalog

- [How to Unlock a User's Account](./logins/SOP-AUTH-001-001.md) - Category: `logins` - This playbook automates the process of finding a user's account on the L1 Support Platform and unlocking it if it's locked due to repeated failed login attempts. It includes a critical check to prevent unlocking accounts that are flagged for security review, which require escalation.
- [How to Reset a User's Password (Admin-Assisted)](./logins/SOP-AUTH-003-001.md) - Category: `logins` - This playbook automates the process for an L1 admin to reset a user's password directly via the L1 Support Platform when self-service options are unavailable. It involves searching for the user by email and then performing an admin-assisted password reset.
- [How to Reset a User's MFA Device](./logins/SOP-AUTH-004-001.md) - Category: `logins` - This playbook automates the process of resetting a user's Multi-Factor Authentication (MFA) device when they have lost or replaced their phone, or reinstalled their authenticator app, leading to lockout. It searches for the user, verifies their current MFA status, and if enabled, performs an MFA reset.
- [Disable Multi-Factor Authentication (MFA) for a User with Password Confirmation](./logins/SOP-AUTH-006-001.md) - Category: `logins` - This playbook disables MFA for a user after confirming their current password, as required by the SOP. The user's password is verified by attempting a no-op password change, and MFA is disabled only if the password is confirmed.
- [Find User Account with Partial Details](./logins/SOP-AUTH-009-001.md) - Category: `logins` - Search for a user account in the L1 Support Platform using partial details (name, partial email, etc.) to identify the correct account before proceeding with further actions.
- [Account Unlock Procedure](./logins/SOP-account-unlock-procedure-001.md) - Category: `logins` - Automated procedure to search for a locked user account by email, unlock it if locked, verify the unlock, and notify the user via email.
- [Handle Suspicious Login Report](./logins/SOP-auth-007-001.md) - Category: `logins` - Locks a user account and retrieves audit logs for suspicious login activity, then escalates to security team. Automated steps include account lookup, audit log retrieval, and account locking.
- [Auth0 User Account Maintenance Procedure](./logins/SOP-auth0-user-account-maintenance-procedure-001.md) - Category: `logins` - This playbook automates the procedure to search for an Auth0 user account by email, check if the account is locked, unlock it if necessary, and verify the updated status.
- [L1 Network Connectivity Troubleshooting via Command Prompt](./network/SOP-NET-001.md) - Category: `network` - This playbook provides a step-by-step procedure to diagnose, isolate, and resolve a user's inability to connect to the internet or internal company network resources using native Windows command-line tools (Windows 10/11). It covers wired and Wi-Fi connectivity issues where the OS boots normally and the user can reach a command prompt. Local Administrator privileges are assumed for command execution.
- [AirRetailer VPN and Remote Desktop Connection Setup](./network/SOP-airretailer-vpn-rdp-001.md) - Category: `network` - This playbook automates the process of connecting to the AirRetailer VPN and then establishing a Remote Desktop session to an office PC, including client installation and configuration based on the user's personal laptop OS.
- [Software Application Unblock Request (IFEO Debugger Removal)](./software/SOP-L1-APP-001.md) - Category: `software` - Automated playbook to identify and remove Image File Execution Options (IFEO) debugger entries blocking a Windows application, including connectivity verification, registry inspection, and policy refresh.
- [Check and Terminate a Hung Application – Windows](./system/SOP-Check-and-Terminate-a-Hung-Application-Windows-001.md) - Category: `system` - This procedure describes the standard steps to verify that an application is running and to forcibly terminate it when it has stopped responding (hung).
- [Disk Error Diagnosis and Repair via Chkdsk](./system/SOP-STG-003.md) - Category: `system` - To identify and repair filesystem structure corruption, bad logical storage blocks, and read/write drive anomalies causing performance bottlenecks on client storage assets (HDDs and SSDs) experiencing extreme latency or error warnings.
- [Corrupted System File Repair](./system/SOP-SYS-002-001.md) - Category: `system` - This playbook automates the repair of corrupted operating system files on Windows 10 and 11 using DISM and SFC tools. It aims to resolve application hangs, patch random Blue Screen of Death (BSOD) errors, and restore core Windows stability by checking and repairing the Windows Component Store and active system files, followed by a system reboot.
