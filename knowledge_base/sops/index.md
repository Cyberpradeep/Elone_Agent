# Active Playbooks Catalog

- [How to Unlock a User's Account](./logins/SOP-AUTH-001.md) - Category: `logins` - This playbook automates the process of unlocking a user's account on the L1 Support Platform after repeated failed login attempts, ensuring quick resolution and preventing duplicate tickets. It includes steps to search for the user, confirm their lock status, and perform the unlock action, with a check for security review locks that require escalation.
- [How to Reset a User's Password (Admin-Assisted)](./logins/SOP-AUTH-003.md) - Category: `logins` - Admin-assisted password reset for users unable to use self-service, allowing direct temporary password setting or reset link generation based on admin choice.
- [How to Reset a User's MFA Device](./logins/SOP-AUTH-004.md) - Category: `logins` - This playbook automates the process of resetting a user's Multi-Factor Authentication (MFA) device when they lose or replace their phone, ensuring they can regain access to their account.
- [Disable MFA for a User](./logins/SOP-AUTH-006-001.md) - Category: `logins` - This playbook disables Multi-Factor Authentication (MFA) for a user after confirming their current password, as requested by the user or admin.
- [Handle Suspicious Login Report](./logins/SOP-AUTH-007-001.md) - Category: `logins` - This playbook automates the handling of a suspicious login report by reviewing recent login activity for a user's account and locking the account as a precautionary measure. The playbook ensures compliance with security protocols by escalating the issue to the security team after locking the account.
- [Find a User's Account Using Partial Details](./logins/SOP-AUTH-009-001.md) - Category: `logins` - This playbook automates the process of searching for a user's account in the L1 Support Platform using partial details (e.g., partial email, name, or employee ID). It ensures the correct account is identified before proceeding with further actions.
- [Account Unlock Procedure](./logins/SOP-account-unlock-procedure-001.md) - Category: `logins` - This playbook automates the procedure for unlocking a user account in the support platform. It searches for the user by email, checks if the account is locked, unlocks it if necessary, verifies the unlock, and sends a confirmation email to the user.
- [Auth0 User Account Maintenance Procedure](./logins/SOP-auth0-user-account-maintenance-procedure-001.md) - Category: `logins` - This playbook automates the process of searching for an Auth0 user account by email, checking if the account is locked, unlocking it if necessary, and verifying the updated status.
- [AirRetailer VPN and Remote Desktop Setup](./network/SOP-AirRetailer-VPN-RDP-001.md) - Category: `network` - This playbook automates the process of setting up AirRetailer VPN using Cisco AnyConnect and then establishing a Remote Desktop connection to an office PC.
- [L1 Network Connectivity Troubleshooting via Command Prompt](./network/SOP-NET-001.md) - Category: `network` - This playbook provides a step-by-step procedure for L1 Helpdesk technicians to diagnose, isolate, and resolve a user's inability to connect to the internet or internal company network resources using native Windows command-line tools. It covers wired and Wi-Fi connectivity issues on Windows 10/11 workstations where the OS boots normally and a command prompt is accessible with elevated privileges.
- [Software Application Unblock Request (IFEO Debugger Entry Removal)](./software/SOP-L1-APP-001.md) - Category: `software` - Automated playbook to identify and remove an Image File Execution Options (IFEO) debugger entry blocking a software application on a Windows endpoint. Includes connectivity checks, registry inspection, block removal, policy refresh, and verification.
- [Disk Error Diagnosis and Repair via Chkdsk](./storage/SOP-stg-003-disk-error-diagnosis-and-repair-001.md) - Category: `storage` - This playbook automates the diagnosis and repair of filesystem structure corruption, bad logical storage blocks, and read/write drive anomalies on Windows HDDs and SSDs using chkdsk. It includes a rapid read-only scan, deep repair with error correction and sector recovery, and a forced reboot to initialize the repair scan.
- [Corrupted System File Repair using DISM and SFC](./system/SOP-SYS-002-001.md) - Category: `system` - This playbook repairs corrupted operating system files, resolves application hangs, addresses random Blue Screen of Death (BSOD) errors, and restores core Windows stability using DISM and SFC tools.
- [Check and Terminate a Hung Application – Windows](./system/SOP-hung-application-001.md) - Category: `system` - This playbook verifies if a specified application is running on a Windows system and, if confirmed to be running and unresponsive, forcibly terminates its process.
