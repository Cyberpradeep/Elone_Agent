# Active Playbooks Catalog

- [Disable MFA for a User](./logins/SOP-AUTH-006-001.md) - Category: `logins` - Disables Multi-Factor Authentication (MFA) for a user account after confirmed request, requiring the user's current password for security confirmation.
- [Handle Suspicious Login Report](./logins/SOP-AUTH-007-001.md) - Category: `logins` - Procedure to lock a user account and escalate to security team upon receiving a suspicious login report. Includes steps to review audit logs and prevent further access during investigation.
- [Find User Account with Partial Details](./logins/SOP-AUTH-009-001.md) - Category: `logins` - Search for a user account using partial details (e.g., partial email, name) to identify the correct account before proceeding with further actions.
- [Unlock a User's Account](./logins/SOP-auth-001-001.md) - Category: `logins` - Automated playbook to search for a locked user account, verify lock status, and unlock the account if it is a standard lockout. Escalates if the account is locked for security review.
- [Admin-Assisted User Password Reset](./logins/SOP-auth-003-001.md) - Category: `logins` - Admin procedure to reset a user's password when self-service methods fail. Includes account verification, temporary password generation, and secure delivery instructions.
- [Reset User's MFA Device](./logins/SOP-auth-004-001.md) - Category: `logins` - Automated playbook to reset a user's MFA device in the L1 Support Platform when they lose access to their authenticator app. Verifies account existence, checks current MFA status, and performs MFA reset if enabled.
- [L1 Network Connectivity Troubleshooting via Command Line](./network/SOP-NET-001.md) - Category: `network` - Automated playbook for diagnosing and resolving Windows network connectivity issues using CLI tools. Covers DHCP, local TCP/IP stack, gateway reachability, external connectivity, and DNS resolution. Escalates to L2 with diagnostic data if unresolved.
- [Software Application Unblock via IFEO Debugger Entry Removal](./software/SOP-APP-001.md) - Category: `software` - Automated playbook to identify and remove Image File Execution Options (IFEO) debugger entries blocking approved software applications on Windows endpoints. Includes connectivity verification, registry inspection, remediation, and policy refresh.
- [Check and Terminate a Hung Application – Windows](./software/SOP-DYN-001.md) - Category: `software` - Verifies if a specified application process is running and forcibly terminates it if unresponsive. Ensures immediate recovery of system resources while warning of potential data loss.
- [Disk Error Diagnosis and Repair via Chkdsk](./storage/SOP-STG-003.md) - Category: `storage` - Identifies and repairs filesystem corruption, bad sectors, and read/write anomalies on HDDs/SSDs using chkdsk. Includes read-only diagnostic, deep repair, and reboot steps with user authorization checks.
- [Resolution of OS Corruption using DISM and SFC](./system/SOP-SYS-002.md) - Category: `system` - Repairs operating system files, resolves application hangs, patches random BSOD errors, and restores core Windows stability using DISM and SFC tools.
