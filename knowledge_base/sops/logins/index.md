# Logins Playbooks Catalog

- [Unlock a User's Account](./SOP-AUTH-001-001.md) - This playbook automates the process of unlocking a user's account in the L1 Support Platform. It searches for the user by email, confirms their lock status, and unlocks the account if it is locked due to failed login attempts.
- [Account Unlock Procedure](./SOP-account-unlock-procedure-001.md) - This playbook automates the procedure for unlocking a user account in the support platform. It searches for the user by email, checks if the account is locked, unlocks it if necessary, verifies the unlock, and sends a confirmation email to the user.
