# Logins Playbooks Catalog

- [How to Unlock a User's Account](./SOP-AUTH-001-001.md) - This playbook automates the process of finding a user's account on the L1 Support Platform and unlocking it if it's locked due to repeated failed login attempts. It includes a critical check to prevent unlocking accounts that are flagged for security review, which require escalation.
- [How to Reset a User's Password (Admin-Assisted)](./SOP-AUTH-003-001.md) - This playbook automates the process for an L1 admin to reset a user's password directly via the L1 Support Platform when self-service options are unavailable. It involves searching for the user by email and then performing an admin-assisted password reset.
- [How to Reset a User's MFA Device](./SOP-AUTH-004-001.md) - This playbook automates the process of resetting a user's Multi-Factor Authentication (MFA) device when they have lost or replaced their phone, or reinstalled their authenticator app, leading to lockout. It searches for the user, verifies their current MFA status, and if enabled, performs an MFA reset.
- [Disable Multi-Factor Authentication (MFA) for a User with Password Confirmation](./SOP-AUTH-006-001.md) - This playbook disables MFA for a user after confirming their current password, as required by the SOP. The user's password is verified by attempting a no-op password change, and MFA is disabled only if the password is confirmed.
- [Find User Account with Partial Details](./SOP-AUTH-009-001.md) - Search for a user account in the L1 Support Platform using partial details (name, partial email, etc.) to identify the correct account before proceeding with further actions.
- [Account Unlock Procedure](./SOP-account-unlock-procedure-001.md) - Automated procedure to search for a locked user account by email, unlock it if locked, verify the unlock, and notify the user via email.
- [Handle Suspicious Login Report](./SOP-auth-007-001.md) - Locks a user account and retrieves audit logs for suspicious login activity, then escalates to security team. Automated steps include account lookup, audit log retrieval, and account locking.
- [Auth0 User Account Maintenance Procedure](./SOP-auth0-user-account-maintenance-procedure-001.md) - This playbook automates the procedure to search for an Auth0 user account by email, check if the account is locked, unlock it if necessary, and verify the updated status.
