# Software Playbooks Catalog

- [Software Application Unblock via IFEO Debugger Entry Removal](./SOP-APP-001.md) - Automated playbook to identify and remove Image File Execution Options (IFEO) debugger entries blocking approved software applications on Windows endpoints. Includes connectivity verification, registry inspection, remediation, and policy refresh.
- [Check and Terminate a Hung Application – Windows](./SOP-DYN-001.md) - Verifies if a specified application process is running and forcibly terminates it if unresponsive. Ensures immediate recovery of system resources while warning of potential data loss.
