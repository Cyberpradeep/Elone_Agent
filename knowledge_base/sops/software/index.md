# Software Playbooks Catalog

- [Software Application Unblock Request](./SOP-L1-APP-001.md) | Platform: `system` | Triggers: `ifeo, unblock, application, debugger, registry, block` | Automated workflow to verify endpoint connectivity, inspect registry for IFEO Debugger blocks, remove the block, refresh policy, and verify removal.
- [Check and Terminate a Hung Application – Windows](./SOP-L1-APP-002.md) | Platform: `system` | Triggers: `terminate, hung, application, taskkill, tasklist` | Automated workflow to verify if a specified application process is running and, if so, to forcibly terminate it.
- [Check and Terminate a Hung Application – Windows](./SOP-L1-WIN-002.md) | Platform: `system` | Triggers: `hung, terminate, taskkill, tasklist, unresponsive, application` | Automated workflow to verify if a specific application process is running and forcibly terminate it if detected.
