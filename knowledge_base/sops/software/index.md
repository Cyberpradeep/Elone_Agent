# Software Playbooks Catalog

- [Software Application Unblock Request](./SOP-L1-APP-001.md) | Platform: `system` | Triggers: `ifeo, unblock, application, debugger, registry` | Automated workflow to verify endpoint connectivity, inspect registry for IFEO Debugger blocks, remove the block, and refresh policy.
- [Check and Terminate a Hung Application – Windows](./SOP-L1-APP-002.md) | Platform: `system` | Triggers: `hung, terminate, taskkill, tasklist, unresponsive, application` | Automated workflow to verify if a specific application process is running and forcibly terminate it if confirmed.
- [Software Application Cache and Credential Vault Reset](./SOP-L1-APP-003.md) | Platform: `system` | Triggers: `cache, reset, hang, freeze, lockfile, credential, vault, application` | Automated workflow to diagnose and resolve application launch hangs, corrupted local cache locks, and frozen credential states on Windows endpoints by terminating processes, clearing cache, and restarting services.
