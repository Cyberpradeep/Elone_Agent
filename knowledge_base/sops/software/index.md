# Software Playbooks Catalog

- [Software Application Unblock Request](./SOP-L1-APP-001.md) | Platform: `system` | Triggers: `ifeo, unblock, application, debugger, registry` | Automated workflow to verify endpoint connectivity, inspect registry for IFEO Debugger blocks, remove the block, and refresh local group policy.
- [Check and Terminate a Hung Application – Windows](./SOP-L1-APP-002.md) | Platform: `system` | Triggers: `hung, terminate, application, taskkill, tasklist, unresponsive` | Automated workflow to verify if a specified application process is running on a Windows system and, if so, forcibly terminate it.
- [Check and Terminate a Hung Application – Windows](./SOP-L1-WIN-APP-001.md) | Platform: `system` | Triggers: `hung, terminate, taskkill, tasklist, process, unresponsive` | Automated procedure to verify if an application process is running on a Windows system and forcibly terminate it if unresponsive or hung.
- [Check and Terminate a Hung Application – Windows](./SOP-check-and-terminate-a-hung-application-windows-001.md) | Platform: `windows` | Triggers: `windows, terminate, hung, application, taskkill, tasklist, unresponsive, force kill` | Standard operating procedure to verify whether a target Windows desktop application is running and forcibly terminate it if unresponsive.
- [Software Application Unblock Request](./SOP-l1-app-001-001.md) | Platform: `system` | Triggers: `ifeo, application, unblock, debugger, blocked, applocker` | Automated workflow to identify and remove Image File Execution Options (IFEO) registry debugger entry application blocks on Windows endpoints, refresh group policies, and verify block removal.
