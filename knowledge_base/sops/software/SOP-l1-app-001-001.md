# Software Application Unblock Request Playbook

## Overview
Automated workflow to identify and remove Image File Execution Options (IFEO) registry debugger entry application blocks on Windows endpoints, refresh group policies, and verify block removal.

## Execution Steps
- **Step 1**: Verify endpoint connectivity using Test-Connection (`Test-Connection {{entities.hostname}} -Count 2`)
- **Step 2**: Identify application blocking mechanism by querying IFEO registry key (`reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.application}}.exe"`)
- **Step 3**: Remove IFEO Debugger value to unblock application execution (`reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.application}}.exe" /v Debugger /f`) [Fallback: `reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.application}}.exe" /f`]
- **Step 4**: Refresh local Group Policy settings (`gpupdate /force`)
- **Step 5**: Verify IFEO block removal by querying registry key again (`reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.application}}.exe"`)
