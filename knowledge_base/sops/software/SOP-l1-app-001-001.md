# Software Application Unblock Request Playbook

## Overview
Identifies and removes Image File Execution Options (IFEO) debugger registry entries blocking software application execution on a Windows endpoint, followed by policy refresh and verification.

## Execution Steps
- **Step 1**: Verify Endpoint Connectivity to the target system using Test-Connection. (`Test-Connection {{entities.hostname}} -Count 2`)
- **Step 2**: Identify Application Blocking Mechanism by querying the IFEO registry key for the executable. (`reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.executable}}"`)
- **Step 3**: Remove IFEO Debugger registry entry blocking application execution. (`reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.executable}}" /v Debugger /f`) [Fallback: `reg delete "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.executable}}" /f`]
- **Step 4**: Refresh Local Group Policy to enforce registry updates. (`gpupdate /force`)
- **Step 5**: Verify IFEO block removal by querying the IFEO registry key again. (`reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\{{entities.executable}}"`)
