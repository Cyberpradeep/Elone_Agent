# Storage Playbooks Catalog

- [Disk Error Diagnosis and Repair via Chkdsk](./SOP-stg-003-disk-error-diagnosis-and-repair-001.md) - This playbook automates the diagnosis and repair of filesystem structure corruption, bad logical storage blocks, and read/write drive anomalies on Windows HDDs and SSDs using chkdsk. It includes a rapid read-only scan, deep repair with error correction and sector recovery, and a forced reboot to initialize the repair scan.
