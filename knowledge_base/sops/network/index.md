# Network Playbooks Catalog

- [L1 Network Connectivity Troubleshooting via Command Prompt](./SOP-NET-001.md) - This playbook provides a step-by-step procedure to diagnose, isolate, and resolve a user's inability to connect to the internet or internal company network resources using native Windows command-line tools (Windows 10/11). It covers wired and Wi-Fi connectivity issues where the OS boots normally and the user can reach a command prompt. Local Administrator privileges are assumed for command execution.
- [AirRetailer VPN and Remote Desktop Connection Setup](./SOP-airretailer-vpn-rdp-001.md) - This playbook automates the process of connecting to the AirRetailer VPN and then establishing a Remote Desktop session to an office PC, including client installation and configuration based on the user's personal laptop OS.
