# Network Playbooks Catalog

- [AirRetailer VPN and Remote Desktop Setup](./SOP-AirRetailer-VPN-RDP-001.md) - This playbook automates the process of setting up AirRetailer VPN using Cisco AnyConnect and then establishing a Remote Desktop connection to an office PC.
- [L1 Network Connectivity Troubleshooting via Command Prompt](./SOP-NET-001.md) - This playbook provides a step-by-step procedure for L1 Helpdesk technicians to diagnose, isolate, and resolve a user's inability to connect to the internet or internal company network resources using native Windows command-line tools. It covers wired and Wi-Fi connectivity issues on Windows 10/11 workstations where the OS boots normally and a command prompt is accessible with elevated privileges.
