# Network Playbooks Catalog

- [AirRetailer VPN and Remote Desktop Setup Playbook](./SOP-airretailer-vpn-rdp-setup-001.md) - This playbook automates the setup of AirRetailer VPN using Cisco AnyConnect and establishes a remote desktop connection to an office PC. It covers deriving the VPN username, logging into the VPN portal, downloading and installing the VPN client, configuring VPN settings, connecting to VPN, collecting the local IP address, and setting up a remote desktop session.
