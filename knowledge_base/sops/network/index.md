# Network Playbooks Catalog

- [AirRetailer VPN and Remote Desktop Setup Playbook](./SOP-airretailer-vpn-rdp-setup-001.md) - Automates the setup of AirRetailer VPN using Cisco AnyConnect and establishes a Remote Desktop connection to an office PC. Steps include deriving VPN username, logging into the VPN portal, installing the VPN client, configuring settings, connecting to VPN, retrieving office PC IP, and initiating RDP.
