# Reset a Locked-Out User's Password via CoreID Admin Console Playbook

## Overview
This playbook automates the process of resetting a locked-out user's password in the CoreID Admin Console. It includes steps for locating the user, verifying their identity, generating a temporary password, and resolving the ticket with an audit note.

## Execution Steps
- **Step 1**: Search for the user in CoreID Admin Console using the employee ID to confirm account status. [Platform: `solandra` | Tool Call: `solandra.search_user({"employee_id": "{{{{entities.employee_id}}}}"})`]
- **Step 2**: Verify the caller's identity using the CoreID identity verification checklist. [Platform: `solandra` | Tool Call: `solandra.verify_caller_identity({"user_id": "{{{{variables.user_id}}}}", "employee_id": "{{{{entities.employee_id}}}}", "manager_name": "{{{{entities.manager_name}}}}", "department": "{{{{variables.department}}}}", "phone_last4": "{{{{entities.phone_last4}}}}"})`]
- **Step 3**: Generate a temporary password for the locked user and enable force change at next sign-in. [Platform: `solandra` | Tool Call: `solandra.generate_temporary_password({"user_id": "{{{{variables.user_id}}}}"})`]
- **Step 4**: Resolve the ticket with an audit note detailing the actions taken. [Platform: `solandra` | Tool Call: `solandra.resolve_ticket({"ticket_id": "{{{{entities.ticket_id}}}}", "resolution_note": "Identity verified (2 of 4 checks). Temporary password issued via CoreID. Force-change-at-next-sign-in enabled. No OTP sent - admin-mediated reset per policy."})`]
